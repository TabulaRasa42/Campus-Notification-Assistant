## Issue #3：验收通过

- 事项、时间和材料可点击定位依据，使用 Qt UTF-16 坐标；测试覆盖中文、换行、emoji、
  重复片段和旧版已保存待办。重复片段必须有正确位置或由用户重新选取。
- 缺失字段显示“原文未提及”；缺少年份、相对日期、冲突时间保留原话和待确认标记，
  不按当天推算、不添加时刻，不将活动开始日期当成确定截止日期。
- 结构合法但无效引用保留在草稿中，禁止对应保存；支持选取真实片段、用户补充或移除可选字段。
  AI 自报用户补充来源不能绕过校验，材料内容与依据不符也须核对。
- 缺失与待确认时间可以保存，重启读取保持标记；日期字段保持日期精度。
- 修改通知使旧结果失效；空结果明确提示且不生成空白待办。
- 证据：`tests/test_evidence_time.py`（21 项）、相关 QML 与组合测试。
  独立审查另用 300 行原文实测选择依据后滚动到可视区。

## Issue #5：验收通过

- 网络连接／超时、HTTP 500／502／503／504 最多自动重试一次。
  密钥、余额、权限、限流、非暂时错误、空响应、JSON 或结构错误不自动重复请求。
- 提取在后台运行，加载状态可见，界面响应；错误提供安全原因，保留完整输入。
  用户修正密钥后主动重试可恢复，无静默截断、失败待办或旧草稿误保存。
- 请求只发送当前通知和必要指令，不上传已有待办；通知内指令只作为数据。
- 点击时预留不可变 source 和 generation；排队任务、改原文、重新提取及丢弃后的过期结果
  都不能覆盖当前草稿。控制器也忽略过期完成消息，包括成功、失败及空结果。
- 保存与编辑串行，SQLite 事务整体提交；重复确认幂等，写锁失败保留草稿并可重试。
- 证据：`tests/test_failures.py`、`tests/test_qml.py`、组合测试及单独真实 API 样例。
