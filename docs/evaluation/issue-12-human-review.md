## 安全的离线界面

在仓库根目录执行以下命令。工具使用本批真实调用的录制响应、内存凭据和临时SQLite，
不会联网或读写真实待办库。窗口标题含“离线验收”，关闭进程后临时数据清理。
界面“API Key已配置”对应内存中的离线占位值，不是真实密钥。

```powershell
.venv/Scripts/python.exe -X utf8 tools/review_issue12.py --case M01 --trial 1
```

1. 点击事项，检查左侧定位的只是比赛介绍，不能支持报名动作。
2. 在左侧原文选择“请大家积极报名！”，点击事项的“修正／选择依据”，保留事项名并确认修正。
3. 检查缺年截止仍待确认、材料仍显示“原文未提及”；确认保存，再从待办列表打开核对原文与引用。
4. 关闭后执行下一条命令。

```powershell
.venv/Scripts/python.exe -X utf8 tools/review_issue12.py --case M02 --trial 3
```

1. 向下滚动结果，检查两项材料都有全体报名者、报名时上传、电子版／一张一寸限定。
2. 点击材料查看引文：目前从“报名时上传”开始。请独立核对它是否足够支持“所有报名者”的主体；
   代理按保守规则记为依据不足，即使你认可这一处也不消除M01的不合格。
3. 选择“请所有报名者”开始至该句末尾的完整原句，分别修正两项材料的依据，保留说明和关系。
4. 确认保存并回查，检查两项仍均必需，没有变成二选一。

```powershell
.venv/Scripts/python.exe -X utf8 tools/review_issue12.py --case M12 --trial 1
```

1. 向下滚动，检查证件原件组、服务台核验、明确“材料关系待核对”，以及另交一张两寸照。

工具同样支持本批其他样例及1—3轮；无需重新调用API。

该模式只验证记录操作，不能作为原自动提取的语义通过成绩。
