# 校园通知助手

Python + PySide6 / Qt Quick 桌面应用。本分支在 Issue #2、#3、#5、#7、#12 的基础上实现 #4 和 #6：
粘贴通知 → 重复提示 → 提取多事项 → 逐项修正与选择 → 整体保存 → 编辑、完成／恢复、删除 → 重启回查。
缺失信息和歧义时间可保留；暂时网络故障最多自动重试一次。

## 开发启动（Windows）

安装 uv 后，在仓库目录执行：

```powershell
uv sync --locked
uv run campus-notifications
```

Python 3.12 由 `.python-version` 指定，依赖版本记录在 `uv.lock`。
密钥在应用“配置 API Key”中输入，存入当前用户 Windows 凭据存储。
界面不回显已有密钥。不要将密钥粘贴到通知输入框、仓库或聊天中。

默认数据位于当前用户本地应用数据目录（应用内显示具体 SQLite 路径）。
未确认草稿只保留在内存，清空或退出前会提示。

## 手动验收

1. 启动，配置有效个人 DeepSeek Key，关闭并重启，确认显示“已配置”。
2. 粘贴下列不含个人信息的样例并点击提取。加载中窗口应保持响应。
3. 核对右侧事项、截止日期、两份材料及各自依据；左侧完整原文保持不变。
4. 确认前清单没有新增待办；点击“确认保存”后新增一条，多次点击不重复。
5. 从清单打开，检查原文、日期、材料和依据。退出重启后重复检查。
6. 提取后尝试清空或退出，检查丢弃提示；错误密钥／断网后输入应仍保留。

```text
实践项目报名通知
请于2026年11月15日前完成实践项目报名，提交报名表和学生证明。
```

点击字段可定位原文依据。“修正”独立编辑字段，无需预先选取原文；“选择依据”打开独立窗口，
在完整通知中选择支持该字段的原文。无效或位置不明的引用保留为待核对，确认保存前须选取真实依据，
或明确标为用户补充内容、移除可选字段。修改待核对截止时间后，其他字段操作不会覆盖修正内容。
材料只列当前事项明确要求自行准备、提交或携带的对象，并保留条件、阶段、处理方式及或／且关系。
材料为空显示“原文未提及”，不表示无需材料；其他阶段文件、检查行为和未要求自备的现场签署文件不列入。
缺失信息显示“原文未提及”，相对日期、缺少年份、冲突时间显示“待确认时间”，
均可保存。修改通知原文会使旧提取结果失效；没有办理事项时不会生成空白待办。

再次粘贴完全相同的已保存通知时，可查看关联的全部待办、取消，或明确继续重新提取。
重新提取后仍须确认另行保存，原记录不被覆盖。空白或换行不同的文本不作相同通知处理。
密钥、余额、权限或返回结构错误不会自动重复调用；失败保留全文，可修正配置后主动重试。

未保存多事项草稿可新增、移除、逐项修正和选择，选中事项一次事务保存；重复确认不重复创建。
已保存待办可独立编辑，保存失败保留编辑；完成、恢复未完成和删除在重启后保持。
编辑待办不改写通知原文，不影响同一通知的其他待办。旧记录继续读取，不自动补材料条件。
提醒与托盘、安装包属于后续任务。
生产调用始终使用真实 DeepSeek，不为模糊日期猜测年份或时刻。

#4/#6 的独立离线桌面入口、操作与反馈见 [本批验收](docs/acceptance-issues-4-6.md)。
它使用合成固定响应和演示数据库；本批 [当前状态](docs/status-issues-4-6.md) 分别记录功能检查、模型评测与用户验收。

## 验证

```powershell
uv run python tools/check.py
```

测试调用真实应用服务和临时 SQLite。HTTP 响应在网络边界替换。
该入口依次运行Ruff、mypy、pytest，固定offscreen Qt并禁用评测工具的真实调用；
GitHub的Windows CI使用同一命令。评测和用户验收流程见[交付约定](docs/agents/delivery.md)。
自动化测试在外部凭据后端使用隔离的内存替身，不访问真实 Windows 凭据；
QML 默认可通过 `$env:QT_QPA_PLATFORM = 'offscreen'` 无界面运行。
生产环境仍只使用 Windows 凭据存储。真实凭据与网络验收和自动化测试分开执行。

下列是历史单事项真实调用工具，运行会上传合成样例并消耗 API 用量，不是本批离线验收入口。
代理如需新增真实调用，必须先按交付约定提交固定候选执行计划并取得明确授权：

```powershell
uv run python tools/live_acceptance.py
```

脚本也可读取当前进程安全配置的 DEEPSEEK_API_KEY，不读取普通 .env 文件，
不接受命令行密钥，不输出原始 HTTP 错误或密钥。无凭据退出码为 2。
该脚本使用临时数据库，不会向你的实际待办清单写入样例。
